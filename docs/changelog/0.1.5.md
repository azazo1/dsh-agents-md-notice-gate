# dsh-agents-md-notice-gate v0.1.5

Date: 2026-08-28

本版本改进 AGENTS 变化确认失败时的提示, 并防止模型把确认回应当作本轮最终回答.

## Highlights

- 确认格式不正确时, 指出第一行标记或第二行变化说明的具体问题, 并引用实际应答.
- 有效确认回应不能结束当前 turn, 输出 marker 后必须继续原先未完成的工作.

## Features

- 插件: 确认失败时对照当前应答指出缺少反斜杠, 标记未独占一行, 第二行前缀不匹配, 以及前缀后没有变化内容等情况.
- 插件: 确认后若模型试图结束本轮, 会自动 steer 继续工作.

## Upgrade Notes

1. 更新插件后重新加载 DSH plugin.
2. 当确认回应被拒绝时, 按提示修正第一行标记或第二行变化说明, 然后继续当前 turn.
3. 输出符合格式的确认后, 不要结束本轮, 继续完成原先工作.
