# dsh-agents-md-notice-gate v0.1.3

Date: 2026-08-22

本版本完善 AGENTS 变化通知门控, 支持在插件重载后继续关联现有会话, 并确保确认后可以继续当前 turn.

## Highlights

- 插件重载后恢复已有会话关联, 避免确认门控状态丢失.
- 确认 AGENTS 变化后继续当前 turn, 减少需要重新发起请求的情况.

## Features

- 插件: 通过 session id 恢复重载前的 agent 关联, 并初始化 agent session registry.

## Bug Fixes

- 插件: 修复 lifecycle listener 使用未初始化 agent registry 导致会话创建失败的问题.
- 插件: 修复 AGENTS 变化确认后 turn 仍然无法继续的问题.

## Upgrade Notes

1. 更新插件后重新加载 DSH plugin.
2. 当 AGENTS.md 发生变化时, 查看指定文件的变化并按确认格式说明实际变化, 然后继续当前 turn.
3. 验证确认后的工具调用可以正常继续执行.
