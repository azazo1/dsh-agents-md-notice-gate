# dsh-agents-md-notice-gate v0.1.6

Date: 2026-09-05

本版本修复最新 DSH 下 AGENTS.md 变化被整文件重注入的问题, 让后续更新重新以 unified diff 出现.

## Highlights

- 后续 `AGENTS.md` / `CLAUDE.md` 等变化会投影为 unified diff, 不再把整份更新原文发给模型.
- 空格和尾部换行也计入变化, 不会因为 trim 后正文相同就放行整文件.
- 相对首次 baseline 的第一次改动是增量 diff, 不是对照空内容的全量 diff.
- 确认回应必须单独成条, 不能和工具调用或最终回答写在同一条消息里.

## Bug Fixes

- 插件: 适配 DSH 0.1.2 的 session API 与 `agent-instructions` 注入时机, 使 diff 投影发生在完整更新进入 enter batch 之后.
- 插件: 修复首次变化被渲染成空文件到全文的全量 diff.
- 插件: 修复仅换行或空白变化时投影失败、整文件泄漏给模型的问题.
- 插件: 明确要求 `[[ACK-AGENTS]]\` 确认独占一条消息.

## Upgrade Notes

1. 更新插件后重启 DSH, bundle 只在 harness 启动时挂载.
2. 确认协议不变: 第一行是 `[[ACK-AGENTS]]\`, 第二行以 `注意到 AGENTS 变化, 变化点在于:` 开头.
3. 可用一次小的 AGENTS.md 改动验证模型收到的是 `<diff>` patch, 而不是 `Updated instructions from:` 整文件.
