# dsh-agents-md-notice-gate v0.1.4

Date: 2026-08-24

本版本改进 AGENTS.md 变化确认提示的格式约束, 让模型更准确地确认实际变化后继续当前 turn.

## Highlights

- 明确要求确认标记独占一行, 并提供具体变化说明.
- 保留删除内容不需要确认的处理规则.

## Bug Fixes

- 插件: 修复 AGENTS 变化提示中确认格式不够明确的问题.
- 插件: 修复变化说明容易与确认标记混写的问题.

## Upgrade Notes

1. 更新插件后重新加载 DSH plugin.
2. 当 AGENTS.md 发生变化时, 先输出独占一行的 `[[ACK-AGENTS]]\` 标记.
3. 在下一行以 `注意到 AGENTS 变化, 变化点在于:` 开头说明新增或修改内容.
4. 删除内容不需要写入变化说明.
